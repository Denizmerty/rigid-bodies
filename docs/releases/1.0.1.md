# Rigid Bodies 1.0.1

This release improves everyday editing, keyboard navigation, saving and measurement review,
with regression coverage for the interaction problems fixed in this version.

## Main fixes

- Fixed invisible toast and overlay regions intercepting clicks, especially around the upper
  middle and right of the window. Cached layouts retain the correct panel and dialog hit regions.
- Made **Custom…** in the playback speed menu open a working multiplier editor, supporting
  0.05× to 4×, input validation and **Reset to 1×**. The toolbar displays the active multiplier.
- Prevented pending numeric edits and slider previews from affecting another object, drawing
  point or document after the selection or setup changes. Escape reliably cancels drafts.
- Fixed keyboard focus, modal shortcut routing and popup dismissal. Space activates the focused
  button, dialogs keep focus, and Escape dismisses the visible layer first.
- Made object selection follow collider geometry, including rotated boxes and compound shapes,
  so empty corners and gaps no longer select an object unexpectedly.

## Editing and navigation

- Improved command search focus, arrow-key navigation, recent commands and selected-result
  contrast across themes. Drawing settings can be found and opened from search.
- Added exact, unit-aware X/Y editing for drawing points, with undo and cancellation. Point
  nudging stays with the selected point, and impact markers no longer intercept point clicks.
- Corrected gravity tilt conversion, preserved numeric precision and improved field caret
  handling. Drawing controls show consistent names and explain unavailable material choices.
- Improved Library search across titles, descriptions, concepts and collections. Collection and
  sort menus, result counts, **Clear filters**, prerequisite links and saved-file browsing behave
  consistently.

## Saving and document history

- Preserve each setup's file destination, title, guide inclusion and save mode through undo/redo.
  Undoing an opened experiment also restores the correct Guide content.
- Track unsaved setup edits independently of ordinary simulation motion. Opening or leaving a
  modified setup offers Save, Discard or Cancel, with safer default focus.
- Capture the intended setup when a save begins and keep subsequent edits marked unsaved.
  Stale asynchronous dialog completions cannot retarget another document or overwrite a newer save.
- Validate a setup before replacing the current document, improve suggested filenames and folder
  selection, and clear playback previews when resetting or loading a setup.

## Measurements and recorded runs

- Improved pinned measurement identity, scope and availability, including objects before the
  first run and useful single-run readouts with names, times and units.
- Review saved runs at their own selected times and graph windows while live recording continues.
  Interpolation respects the recorded interval, and **Back to live** restores the current run.
- Corrected percentage-change formatting and unavailable-value handling so missing samples do
  not appear as valid zeroes.

## Maintenance and distribution

- Expanded application, UI and integration regressions and refreshed UI snapshots and usage
  documentation. C++ changes follow the repository's clang-format configuration.
- Updated shared product metadata and About snapshots to 1.0.1.
- Added version-specific release notes to the checked and checksummed release artifacts. The
  version-tag workflow builds and tests the Windows installer and portable ZIP, then publishes
  the release with these notes, build provenance and SHA-256 checksums.

Download `Rigid-Bodies-1.0.1-windows-x64-setup.exe` for installation or upgrading an existing copy.
The ZIP contains the same runtime files for portable use.
